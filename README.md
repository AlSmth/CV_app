# Gesture Control — управление Android-телефоном жестами через камеру

Фронтальная камера отслеживает руку (MediaPipe Hand Landmarker, 21 точка). Распознанные жесты
превращаются в нажатия, свайпы и системные кнопки через службу специальных возможностей
(AccessibilityService). Всё работает поверх любых приложений.

## Жесты

| Жест | Действие |
|---|---|
| ☝ Указательный палец | двигать курсор (кружок на экране) |
| 👌 Щипок (большой + указательный) | нажатие в точке курсора |
| 👌 Щипок ~1 с | долгое нажатие |
| 👌 Щипок и вести руку | листать / перетаскивать, как пальцем; разжать — отпустить |
| ✊ Кулак, держать 0.7 с | «Назад» |
| ✌ Два пальца, держать 0.7 с | «Домой» |
| 🤟 Три пальца, держать 0.7 с | недавние приложения |

## Сборка

1. Установите [Android Studio](https://developer.android.com/studio) (в комплекте JDK и Android SDK).
2. File → Open → папка `CV_app`. Studio скачает Gradle 8.7 и зависимости.
3. При первой сборке Gradle сам скачает модель `hand_landmarker.task` (~7.5 МБ) в `app/src/main/assets/`.
4. Подключите телефон (Android 8.0+) с включённой отладкой по USB и нажмите ▶ Run.

## Установочный пакет для других устройств

В Android Studio: панель Gradle → app → Tasks → other → `exportApk`. Задача собирает подписанный `install/GestureControl-<версия>.apk` (рядом лежит инструкция «Как установить.txt»).
Ключ подписи — `gesturecontrol-release.jks` и пароли в `keystore.properties` в корне проекта; они не в git.
Сохраните их: обновления, подписанные другим ключом, не встанут поверх уже установленного приложения.

## Первый запуск на телефоне

1. «Разрешить камеру» → разрешите камеру и уведомления.
2. «Включить спец. возможности» → найдите **Gesture Control** → включите.
   - На Android 13+ для приложений не из Play Маркета может появиться «Ограниченная настройка».
     Тогда: Настройки → Приложения → Gesture Control → ⋮ → «Разрешить ограниченные настройки» и повторите.
3. «Запустить управление жестами». Появится уведомление — оттуда же можно остановить.
4. Поставьте телефон на подставку и держите руку в 30–60 см от фронтальной камеры.

## Устройство проекта

- `HandTracker.kt` — обёртка над MediaPipe, возвращает 21 точку руки.
- `GestureRecognizer.kt` — определяет позу и жесты (щипок, перетаскивание, удержание), сглаживает курсор.
  Все пороги — константы в начале класса, их удобно подстраивать.
- `CameraService.kt` — foreground-служба: CameraX → кадр → распознавание; ставит камеру на паузу при выключенном экране.
- `GestureAccessibilityService.kt` — выполняет нажатия/свайпы (`dispatchGesture`) и рисует курсор поверх экрана.
- `MainActivity.kt` — экран настройки.
- `PreviewActivity.kt` — экран «как камера видит руку»: кадр, скелет руки, поза, FPS.

## Ограничения

- Только Android: iOS не даёт сторонним приложениям управлять системой.
- Пока работает камера, расход батареи заметно выше.
- Ориентация рассчитана на портретный режим.
