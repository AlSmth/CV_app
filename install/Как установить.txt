GESTURE CONTROL — управление планшетом жестами через камеру
============================================================

Нужно: Android 8.0 или новее, фронтальная камера.


УСТАНОВКА
---------
1. Перекиньте файл GestureControl-1.2.apk на планшет
   (через Telegram, WhatsApp, Google Диск, USB-кабель — как удобно).
2. Откройте файл на планшете (обычно в «Загрузках» или прямо из мессенджера).
3. Android спросит разрешение устанавливать приложения из этого источника —
   нажмите «Настройки» → включите «Разрешить из этого источника» → назад.
4. Нажмите «Установить». Если Play Защита предупредит о неизвестном
   приложении — «Подробнее» → «Всё равно установить».


НАСТРОЙКА (один раз)
--------------------
Откройте приложение Gesture Control и нажмите кнопки по порядку:

1. «Разрешить камеру» — разрешите камеру и уведомления.

2. «Включить спец. возможности» → найдите Gesture Control
   (иногда в разделе «Скачанные приложения») → включите.

   Если Android пишет «Ограниченная настройка» / «Настройка недоступна»:
   Настройки → Приложения → Gesture Control → ⋮ (три точки вверху справа)
   → «Разрешить ограниченные настройки». Потом повторите шаг 2.

3. «Запустить управление жестами». В шторке появится уведомление —
   оттуда же можно остановить.

Совет: на Xiaomi / Huawei / Samsung разрешите приложению работать в фоне
(Настройки → Приложения → Gesture Control → Батарея → «Без ограничений»),
иначе система может выключать его.


ЖЕСТЫ
-----
Держите руку в 30–60 см от фронтальной камеры.

  ☝  Указательный палец ............ двигать курсор (кружок на экране)
  👌  Щипок (большой + указательный) . нажатие
  👌  Щипок и держать ~1 с ........... долгое нажатие
  👌  Щипок и вести руку ............. листать / перетаскивать, разжать — отпустить
  ✊  Кулак, подержать ............... «Назад»
  ✌  Два пальца, подержать .......... «Домой»
  🤟  Три пальца, подержать .......... недавние приложения

Кнопка «Посмотреть, как камера видит руку» показывает изображение с камеры
и что распознаётся — удобно, чтобы понять, как держать руку.
